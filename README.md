# schipaoAdventure
![Main Title](src/main/resources/assets/schipaoadventure/icon.png)

**A fabric 1.21 mod that adds various fun and interesting features to make your journey more interesting**

---

# Features

- **Custom Classes System**  
  Choose between different playable classes, each with unique abilities, strengths and gameplay styles.

- **Class Change Item**  
  A special item allows players to change their class during the game.

- **Unique Abilities**  
  Every class has custom skills and effects that influence combat, exploration and survival.

- **New Blocks and Items**  
  The mod introduces several new blocks and items designed to expand gameplay and progression.

- **Custom Commands**  
  Includes useful commands for managing classes, abilities and debugging features.

# Commands

Commands included in the mod:

```bash
/class <class>
/class 
```

# Usage

For setup instructions, please see the official Fabric documentation:  
https://docs.fabricmc.net/develop/getting-started/creating-a-project#setting-up

To use the mod:
1. Install Fabric Loader for Minecraft 1.21
2. Place the mod inside the `mods` folder
3. Launch the game with Fabric
4. Select your class and start your adventure
